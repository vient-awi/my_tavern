## 项目定位

- **项目名称**：虫族（占位名，随时可改）
- **形式**：角色卡（世界观设定打包在内嵌世界书里），使用 MVU 变量 + EJS 条件渲染
- **主题**：异星虫族社会的生存与攀升。扮演一只雌虫，走过人生不同阶段
- **体验目标**：沉浸式的社会生存体验 + 角色扮演。玩家要处理的是「怎么在这个社会里活下去、往上走」，而不是打怪升级
- **情感落点**：沉浸感与身份感。玩完一段之后，玩家会觉得「我在那个社会里活过一阵子」

### 核心体验的两个支点

1. **生活质感**：虫族社会的日常是怎么运转的。取蜜、供蜜、论坛闲逛、同事关系、被派往前线、被人议论。
2. **社会压强**：这个社会对每种性别都有默认期待，玩家要面对它、利用它，或者反抗它。

## 世界观概念

**完全架空**。不做任何地球或现实映射。

### 种族与社会结构

虫族有两种性别三分化：雌虫、雄虫、亚雄。比例约 **1 : 19 : 70**，寿命约 700 岁。

- **雌虫**：拥有精神力。精神力完全成长后是虫族的重要战力，多数担任军队总指挥。以虫蜜为唯一食物，自己不能产蜜。
- **雄虫**：唯一有生育能力的性别。为便于生育，体型通常高大壮硕（平均身高约两米），肉身战斗力极强，数量上是主要战力。参军是每位雄虫的义务，参军的统称**军雄**。
- **亚雄**：无生育能力，负责社会各方面的工作——医疗、科研、行政、作战参谋。幼虫都交由亚雄抚养。头脑精密程度可与雌虫媲美。

**外观默认**：雌虫一律为女性外表，亚雄与雄虫一律为男性外表（雄虫为壮硕猛男）。不设其他形态分化。

**社会默认（设定原文）**：三者地位平等。

### 外敌

**翼族**：捕食虫族来进化，与虫族敌对。翼族的存在是虫族社会军事化的根本原因。

### 技术层级

星际文明。有星域、星际舰队、粒子炮、机甲、星历纪年法。

## 洛希边境（新增 · 本卡开局舞台）

**这是本卡最重要的一处新增设定，也是整个开局的支点。**

- 洛希边境（洛希防线）是众人皆知的最危险战场
- **那里的翼族免疫精神攻击** —— 这一条把雌虫最核心的优势直接废掉了
- 雌虫珍贵，不能被浪费在这种战场 → 洛希边境长期只有军雄在坚守
- 于是洛希边境在雌虫之间变成了**禁地**，也是一种谈资：谁去了谁就是不要命
- 防线由**少将凯恩·斯顿**实际指挥，情报部**戴蒙·暗影**中校负责情报，另有第七中队、第三中队、特勤支队、军需处、医疗组等编制

**这个设定为什么好**：它制造了一个「雌虫优势失效」的真空地带。玩家作为雌虫走进这里，天然就失去了社会给雌虫的一切保护与特权——精神力没用、身份压不住人。这一处的体验和虫族腹地是**反着来的**，正好用来打脸那种「雌虫天生高人一等」的幻觉。

### 洛希防线的历史：沙利文大将

军部元帅麾下四将之一，**塞缪尔·沙利文**大将，是洛希防线的一个传奇。

- 他在洛希服役时，**靠不断怀孕分娩、用产出的虫蜜补充体力，守住了防线**
- 这段经历让他成了**军雄们的偶像**
- 他身边常年圈养五六只雌虫。据圈子里的雌虫说，他榨精技术好、产出的蜜销魂醉虫，每只雌虫都心甘情愿留下、自愿灌溉雌精
- 虫族圈子里不少雌虫对他心向往之，想尝一口这位大将的蜜

> **设定作用**：这一条把「雄虫用自身产蜜反哺能量」（设定 §5）绑到了洛希防线上，让这条线有了自己的史观和偶像。而且它给出了一个反差——雌虫在洛希是禁地，但一个雄虫在洛希成了传奇。这正好和主角的处境对照。

## 角色方向

**洛希防线是本卡的主舞台，这里的角色是核心。**

### 主要角色（写完整：基础信息 + 性格调色盘）

| 角色 | 身份 | 定位 |
| --- | --- | --- |
| **林昊** | 上尉，副官，188cm，58岁 | 主角在前往车站途中遇到的那位军雄。在洛希坚守过一段不短的岁月，作战经验充分，**年轻有为**——凭实打实的战功晋升上尉被提为副官。忠诚专一、沉默隐忍、细心体贴。蜜质香甜如雪地煨熟的蜜薯 |
| **凯恩·斯顿** | 洛希防线少将，实际指挥官，218cm，216岁 | 资深老兵。外表暴躁粗鲁满口脏话，内心重情重义。**对雌虫有偏见**——雄兄死于护送雌虫，这是他内心的隐痛。战斗狂热，产蛋频率极高（充分灌溉下一个月四窝）。防线记录：七天七夜守裂缝，临产状态击杀两百余只翼族。蜜质为**烈蜜** |
| **戴蒙·暗影** | 情报部中校，暗影小队负责人，198cm，**268岁（比凯恩年长）** | 洛希防线的**中流砥柱**。沉默寡言的资深情报官，头发全白。满身疤痕，生殖腔有旧伤，擅吹骨笛。战斗诡谲致命。**与凯恩共同撑起洛希防线多年**——凯恩管打仗、他管情报，两人合起来才是完整的洛希防线。蜜质**带铁锈味**（因旧伤） |

> **凯恩与戴蒙的关系是轴心之一，不是摩擦关系。** 两人是配合几十年的老搭档，互相托底。凯恩对谁都拍桌子，唯独不在戴蒙面前拍。戴蒙比凯恩年长，却从不当众纠正他。这条关系给防线提供了「有人一起扛」的底色，和凯恩对雌虫的敌意形成对照。

### NPC（写简要）

罗兰（第七中队队长，金发俊美、嘴上最贫、被碰到就脸红）、威尔斯（少校军需官，眼镜知识分子、说话极慢、私下用物资换人情）、乔纳森（医疗组负责人，眼镜学者气、全防线唯一敢命令凯恩的人）、莫里斯（特勤支队队长，一米八、生殖道极敏感、擅长爆破）、安德烈（第三中队队长，小腹旧伤、坚韧沉稳）、艾伦（参谋，**亚雄**，从不出错也不多话、蜜量少而自卑）

### 一个跨角色的身体机制

**莫里斯与安德烈**之间存在罕见的**生理同步现象**：两人的快感、蜜液分泌甚至宫缩感都能共享。一方高潮会引发另一方同步反应。这是这对角色的核心卖点，写条目时要保留。

### 蜜质机制（重要）

雄虫的蜜质分两层：

1. **基础蜜质固定** —— 是人物属性。如林昊的蜜薯甜香、凯恩的烈蜜、戴蒙的铁锈味、罗兰的清甜、威尔斯的铁锈火药味、乔纳森的酒香、莫里斯的粘稠火药味、安德烈的金属余味、艾伦的清淡甜美
2. **随关系变化** —— 依据设定 §4「不同雌虫向不同雄虫注入雌精得到的虫蜜口感不同」。玩家灌溉他的频率、玩家的精神力等级、双方关系阶段都会影响实际尝到的味道

**为什么这样设计**：基础值让人物有辨识度，变化值让蜜的味道变成**关系状态的读数**——玩家能从味道反推自己在他身上到了哪一步，也能从味道的异常发现「别人碰过他」。这是本卡一条重要的信息渠道。

### 随机生成角色（保留）

洛希防线之外的场景（虫族腹地、论坛、其他星域）仍用 AI 现场生成 + 标签池的做法，保证每次遇到的人都不一样。

### `<user>` 的角色定位

- **身份**：雌虫，军校指挥官院毕业的优秀指挥
- **履历**：毕业后两年内在各个战场拿下数场大捷
- **性格向度**：热衷于挑战，好胜
- **称呼**：第二人称「你」
- **自定义空间**：姓名、外形、具体来历由玩家在开场填写

## 出生与成长设定

### 成熟年龄

- **雄虫 20 岁成熟**（设定原文）
- **雌虫 23 岁成熟**（暂定）
- **亚雄 18 岁成熟**（暂定，因为亚雄更早承担社会工作）

> 暂定理由：雌虫要成长精神力，比雄虫晚；亚雄纯做社会工作，可以更早。如果将来要改，改这一个数就行。

### 幼虫期与抚养

0 到成熟期为止由亚雄抚养，社会统一安排。学校分两条路：**普通教育**和**军校**。主角走的是军校指挥官院。

### 精神力等级表（暂定）

| 等级 | 定位 | 能力表现 |
| --- | --- | --- |
| C | 军校合格线 | 能带小队，指挥半径 50 米，可传递简单指令 |
| B | 优秀毕业生水平 | 团级指挥，指挥半径 500 米，能压制普通翼族 |
| A | 军雌中坚 | 舰队级指挥，可进行精神力攻击 |
| S | 顶尖战力 | 星域级指挥，精神力可实质化 |
| SS | 传说中的存在 | 雌王级别 |
| SSS | 理论极限 | 历史上未出现过 |

> **关于「免疫精神攻击」**：洛希边境的翼族对 C 到 S 级的全部精神手段都免疫。所以这个等级表在洛希边境基本失效——这正是那里的恐怖之处。

## 互动与动态需求

### 两条线

**线一：正文叙事**
玩家在这个世界里生活、行动、与人打交道。AI 用第二人称推进。

**线二：《触角》论坛**
一个雌虫内部的匿名论坛，用户全是雌虫。玩家随时能打开它，刷帖、发帖、点赞、评论、跟网友互动。

**两条线是咬合的，不是并行的装饰**：
- 正文里发生的事会变成论坛上的热帖（你打了胜仗，论坛在讨论你；你纳了雄侍，论坛在扒对方是谁）
- 论坛上的爆料会引正文事件（有人在论坛扒出某个议员的雄侍在公共哺蜜亭喂陌生雌虫 → 这件事在你身边真的发生了）
- 玩家自己在论坛上说错话，会引来现实后果

### 玩家能动性

**完全自由**。长线沙盒，不设强剧情驱动。靠变量累积自然生成事件。

### 需要追踪的动态概念（→ MVU 变量）

按重要性排：

| 追踪什么 | 为什么追踪 |
| --- | --- |
| **当前阶段** | 初入社会 / 军雌生涯 / 王巢与权力，决定加载哪套阶段指导 |
| **精神力等级与成长值** | 雌虫的核心资源，决定战斗能做什么、社会地位到哪 |
| **饱食 / 饥饿** | 雌虫靠虫蜜维生。这是生存压力，也是社交压力 |
| **蜜源名册** | 谁是你的长期蜜源（雄侍）、临时蜜源。关系与供给量 |
| **雄虫关系** | 每个雄虫的亲密度、供给能力、身体状态 |
| **军功与位阶** | 军雌生涯的核心成长轨道 |
| **名气 / 声望** | 社会形象。好名声和坏名声都影响别人怎么对你 |
| **论坛数据** | 帖子、评论、点赞、私信、声望 |
| **网友关系** | 和论坛上那些 ID 的关系，有些人的真实身份会揭晓 |
| **所处位置** | 当前在哪个星域 / 场景 |

### 反馈循环节奏

**长线累积**为主，但每一轮都要有**即时反馈**（一次取蜜、一次论坛互动、一段对话都要有结果）。不做「攒够一百点升一级」那种抽象感。

## 创作方向

- **叙事视角**：第二人称「你」（与你已有卡一致）
- **语言风格**：口语化为主，兼顾描写精度。日常段轻松带点调侃，论坛段更像真人发帖（有语气词、有错别字、有 emoji）
- **文学密度**：适度修辞。不堆砌辞藻，但身体感受和情绪要写到位
- **描写侧重**：**身体感受 + 社会关系**。这个设定的核心是身体与社会的关系，所以写「身体的感觉」和「别人怎么看你」是重点
- **节奏偏好**：日常铺陈为主，事件驱动提速。不赶剧情
- **情绪基调**：以「生存的实在感」为底，可温馨可紧张可荒诞。论坛段允许搞笑

## 开场构思

**采用你提的那个开局。**

- **情境**：主角在洛希边境的车站路上，准备前往这个众人皆知的禁地。为了不引人注目，特意身着便装
- **路上遇到**：一位前去洛希边境战场报道的军雄，两人攀谈起来
- **玩家进入世界的第一印象**：一个把「雌虫不该来这里」写在每个眼神里的地方，而你是自己来的
- **开场信息密度**：渐进揭示。通过和军雄的攀谈自然带出洛希边境的特殊性，不一次性抛设定
- **玩家首步引导**：弱引导。攀谈后的走向由玩家决定
- **开场形式**：**开局面板（自包含 HTML）→ 叙事式第一幕**
  - 面板让玩家填：姓名、外形、出身（暂定选项待定）、初始处境微调
  - 填完进入叙事式第一幕

> 开局面板做多细，等 UI 阶段再定。第一版可以很简。

## 剧情设计

### 三阶段人生线（顺序推进）

> **2026-09-28 变更**：本节已被推翻。主角开局就是军校指挥官院优秀毕业生、上尉、军功三百二十，两年内拿过数场大捷——她已经在军队里，用「初入社会」概括会误导 AI。`主角.人生阶段` 变量与按阶段裁切的 EJS 已从卡中删除，阶段指导改写为单条「洛希线」。以下内容仅作设计过程留档，不再对应卡的实际结构。

**阶段一 · 初入社会**
- 进入洛希边境。精神力在这里没用，身份在这里压不住人
- 第一次真正面对「自己得找蜜源」的现实
- 认识这里的人，理解这里为什么是禁地
- **推进条件**：在这里活下来，并且弄明白自己要什么（留下 / 离开 / 改变这里）

**阶段二 · 军雌生涯**
- 精神力成长期，带队、打翼族、拼军功和晋升
- 核心矛盾：**供蜜与上战场的冲突**。你的蜜源可能是军雄，他也要上战场；你自己也要上前线
- 社会期待与个人选择的摩擦
- **推进条件**：军功与位阶达到某个量级，或触发了王巢的注意

**阶段三 · 王巢与权力**
- 能力出众的雌虫会被王巢选中成为**雌王**
- 卷入王巢规则、蜜源垄断、亚雄平权这类权力与舆论斗争
- 论坛从「闲聊的地方」变成「舆论战场」
- **推进条件**：长线沙盒，不设终点。玩家想结束才结束

### 阶段之间的连续

**前一阶段的选择会决定下一阶段的开局条件。** 具体靠变量携带：
- 精神力等级 → 决定下一阶段能接什么任务、别人怎么看你
- 蜜源名册 → 跟着你走下去，雄侍会老、会受伤、会被调走
- 名声与论坛声望 → 决定下一阶段开局时社会对你的态度
- 认识过的人 → 可能再出现

### 暴露时机与控制策略

- **世界观暴露**：渐进。设定通过具体场景自然带出（吃一次蜜就知道取蜜是怎么回事），不靠大段说明文
- **论坛真相**：论坛上说话的 ID 有些是熟人。什么时候揭晓？——不做主动揭晓机制，靠剧情自然撞上。玩家可能很久之后才发现某个常骂人的 ID 是自己上级
- **控制策略**：用阶段边界控制，不做硬性封锁。阶段指导条目里写「什么时候不能进入下一阶段」，而不是写死「第几天必须发生什么」

## SFW / NSFW

### 分级

**主线 NSFW，解剖式硬核。**

雌茎、雌精、生殖腔、生殖道、肉唇、肉茎、尾勾、虫蜜、虫蛋、临产——这些术语直接用，生理过程按设定写，逐帧描写。

### 性向与关系结构

- **性向**：本世界不存在「同性恋/异性恋」这个框架。性别有三种，「取向」由玩家自己定
- **关系结构**：**开放**。设定原文明确写了社会鼓励雌虫吸食多只不同雄虫的蜜，雌虫可以纳多位雄侍
- **具体关系走向**：由玩家决定。可以是长期一对一，也可以是多蜜源并行，也可以只是纯粹的生存性取蜜

### NSFW 触发与节奏

**主线内容，剧情驱动的部分和玩家主动的部分都有。**
- 取蜜是**生存必需**，所以它会自然地、反复地发生——这是这个设定最强的设定优势，NSFW 不是外挂的模块，是世界的骨架
- 但取蜜不必然是情色的。饿急了去取一次蜜，可以是狼狈的、屈辱的、纯功能性的。这一点由玩家和 AI 共同决定

### 硬性边界（不进卡）

**血腥猎奇** —— 肢解、开膛、内脏特写不做。翼族撕翅、王虫吞噬这类写成战损或吞食的**结果**，不做猎奇特写

> 本卡**不发布**，仅自己游玩。因此不做额外的审查性限制与自我删减——内容按设定写足，只保留上面这一条创作取向上的边界。

### 其他软边界

- **崩坏是可恢复状态**，不做永久性人格抹除
- **不预设角色永久死亡**。固定角色和重要 NPC 不因剧情失败而永久退场

### 文风

**解剖式直白**为主，但它和「身体感受」不冲突——解剖式的准确性 + 身体感受的实感，两者一起用。不写含蓄的隐喻替代，也不写纯器官清单。

## 风格意向

- **参考调子**：你设定文件里那段论坛样例就是最好的风格标尺。那个语感——「骨架是真的大，生殖腔目测能直接吞下我整根雌茎。但试吸时发现他蜜里带股铁锈味」——既有生理的直白，又有真人发帖的松弛。正文和论坛都要往这个语感靠
- **身体与社会的咬合**：这个设定的独到之处是身体直接承载社会功能（产蜜 = 供养全社会的雌虫）。写作时要把这个「身体即公共事务」的感觉写出来

## UI 设计

### 视觉基调

**感官词**（从世界观与情绪基调提炼）：

| 来源 | 抽象表达 | → 感官词 |
| --- | --- | --- |
| 世界观氛围 | 星际军事、荒凉前线 | 冷金属灰、舱内灯带的青白、预警屏的琥珀 |
| 情绪基调 | 硬核但有温度 | 粗糙表面的哑光、边缘被磨圆的金属 |
| 核心冲突 | 身体即公共事务 | 半透明的、能看见内部的容器感 |
| 角色印象 | 雌虫指挥官 | 锐利的折线、克制的留白 |
| 论坛线 | 匿名、松弛、八卦 | 便签纸的暖黄、荧光笔的高亮、手写体 |

**交互人格**：

| 维度 | 状态栏（收束、冷静） | 论坛（散漫、热闹） |
| --- | --- | --- |
| 语速 | 干脆，数值变化直接跳 | 缓慢滚动的信息流 |
| 音量 | 指示灯级别 | 人多嘈杂 |
| 动作 | 展开时像掀开一块仪表板盖板 | 点击像翻页 |
| 距离 | 贴在手边的一小块面板 | 一整个可以钻进去的空间 |
| 回应 | 你不问就不动 | 总有新帖子在冒出来 |

两者刻意做成不同的调性。状态栏是军用的，论坛是平民的。这个反差本身就是「双线叙事」的视觉表达——一个是她作为雌虫军官的现实，一个她作为「落雨天」的另一面。

### 组件构思

**信息优先级**（基于 `schema.ts`）：

- **始终可见**：姓名、人生阶段、饱食度（她是大胃袋，这是最需要随时看的数）、精神力
- **展开可见**：军衔军功声望、尾勾、蜜源名册、雄虫关系、论坛声望
- **情境可见**：饱食度 ≤ 4 时的危险提示条；当前场景与近期事务

**布局模式**：混合型（折叠 + 网格）。折叠状态只留一行标题，展开后是分区网格。

**组件树草图**：

```
状态栏
├─ 标题栏（始终可见，点击切换展开）
│  ├─ 姓名 + 人生阶段徽章
│  ├─ 饱食度条（12 格刻度，不是百分比条）
│  └─ 精神力（数值 + 等级）
├─ 展开区
│  ├─ 世界区块：当前时间 / 区域 / 场景 / 近期事务
│  ├─ 军籍区块：军衔 / 军功 / 所属 / 声望 / 尾勾
│  ├─ 蜜源名册（每只雄虫一张卡：姓名、关系、蜜质、亲密度、供给、身体状态）
│  └─ 雄虫关系（好感度 / 信任度 / 备注）
└─ 情境覆盖：饱食度 ≤ 4 时的横幅提示

《触角》论坛（独立界面，独立占位符）
├─ 顶部：欢迎语（含昵称【落雨天】）
├─ 导航栏：板块切换 / 刷新 / 发布新帖 / 我的主页 / 退出
├─ 公告区
├─ 帖子列表（标题 / 作者 / 摘要 / 点赞 / 评论数）
├─ 帖子详情（正文 + 评论区，可点赞、评论、回复）
├─ 发帖表单
└─ 私信（收件箱）
```

**布局差异**：论坛是独立界面，不是状态栏的一部分。它有自己的占位符与正则，视觉上与状态栏刻意割裂。

### 与 MVU 的接口

两个界面共用同一份 `defineMvuDataStore(Schema, { type: 'message', message_id: getCurrentMessageId() })`，读写的都是 `stat_data`。状态栏只读，论坛可写（发帖、点赞、评论、私信都会写回 `论坛` 段）。
